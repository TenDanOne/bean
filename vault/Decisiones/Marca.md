# Decisión · Marca

- Nombre: «BEAN by ITHOS»; en la UI, «BEAN».
- Estilo ITHOS: kit de SIMU, isotipo ITHOS, tipografía Figtree.
- Paleta propia que **combina** los colores originales de BrightBean con los de ITHOS, como agradecimiento indirecto (de ahí «bean»). **Paleta final pendiente de elección del usuario.**
- No usar logos de BrightBean. Guardián: agente `design-system-bean`.
- Los colores de marca por organización se inyectan como CSS custom properties en runtime (sin rebuild).
- Implementación: Fase 4.
